# AGENTS.md

## 역할
이 저장소의 Codex 에이전트는 Researchi 관리자 프로그램을 단계적으로 구현한다.

## 절대 원칙
1. 한 번에 많은 기능을 구현하지 않는다.
2. 항상 TASKS.md의 현재 단계만 구현한다.
3. 미래 단계 기능을 미리 넣지 않는다.
4. 운영 DB 직접 변경 코드는 최소화한다.
5. XE 연동 코드는 `xe` 모듈에만 둔다.
6. 신청 폼(public form)과 관리자 화면(admin)을 분리된 모듈처럼 유지한다.
7. 동적 질문/답변은 고정 컬럼으로 우회하지 않는다.
8. 거래자용 다운로드는 공고별 질문 정의를 기준으로 동적 생성해야 한다.
9. 보안 기능(CSRF, 해시, 제한, 마스킹)을 생략하지 않는다.
10. 모든 주요 변경은 문서와 함께 유지한다.

## 작업 방식
- 현재 단계에 필요한 파일만 수정한다.
- 변경 후 아래를 반드시 보고한다.
  1. 생성/수정한 파일 목록
  2. 구현한 내용 요약
  3. 다음 가능한 작업

## 금지사항
- 기존 XE 구조를 임의로 광범위하게 변경하지 말 것
- 운영용 값을 코드에 하드코딩하지 말 것
- 역할 분리/다중 관리자 기능을 추가하지 말 것
- React/Next 등 다른 프론트 프레임워크를 끼워 넣지 말 것
- 동적 질문을 `/` 구분 문자열로 다시 합치지 말 것
- 개인정보를 평문 출력/로그에 남기지 말 것
