운영 중인 리서치 사이트를 위한 **관리자 전용 웹 애플리케이션**입니다.  
기존 사용자 사이트와 분리된 구조로 설계되었으며, 공고 운영, 신청자 관리, 블랙리스트 처리, 메일 발송, 로그 관리까지 관리자 업무를 한 곳에서 처리할 수 있도록 개발했습니다.

---

## 프로젝트 소개

기존 리서치 사이트 운영 과정에서는 공고 등록, 신청자 정리, 거래자 전달, 블랙리스트 관리, 메일 발송 등이 수작업으로 처리되는 부분이 많았습니다.  
이 프로젝트는 이러한 운영 흐름을 **관리자 전용 시스템**으로 재구성하여 업무 효율성과 보안성을 높이는 것을 목표로 합니다.

### 핵심 목표
- 공고별 신청자 관리 자동화
- 공고별 동적 신청 폼 운영
- 블랙리스트 처리 정책 반영
- 수동 발송 / 예약 발송 / 임계치 발송 지원
- 로그 기반 운영 관리
- 관리자 보안 강화
